# power-BI-RMS-TITANIC-VIRTUAL-DSAHBORAD
power BI RMS TITANIC VIRTUAL DSAHBORAD
Project Name: RMS Titanic – Executive Demographic & Survival Intelligence.
Main Objective: Analyze Titanic passenger data and identify patterns related to survival, class, gender, age, fare, family, cabin deck, and port.
Technologies Used:
HTML
CSS
JavaScript
Data visualization
CSV export
Interactive Slicers:
Passenger Class
Sex
Port
Family Category
Dynamic KPIs:
Total Passengers
Total Survivors
Survival Rate
Average Fare
Interactive Charts:
Survival by Passenger Class
Age Group & Sex
Cabin Deck Distribution
Port Distribution
Cross-Filtering: Changing a slicer automatically changes the KPIs, charts, and passenger table.
Passenger Detail Table: Displays filtered passenger information such as ID, class, sex, age, deck, port, family category, fare, and survival status.
CSV Export: Users can export the currently filtered data into a CSV file.
Clear Filters: The Clear All Slicers button resets the dashboard.
Key Titanic Metrics:
Total passengers: 891
Survivors: 342
Overall survival rate: approximately 38.4%
Main Data Analysis: The dashboard allows users to investigate relationships between passenger characteristics and survival.
Responsive Design: The dashboard can adapt to desktop, tablet, and smaller screens.
Project Value: Demonstrates skills in dashboard development, data analysis, visualization, JavaScript filtering, KPI creation, and interactive UI design.
Important Limitation: The HTML dashboard does not directly execute the .pbix file; it recreates the Power BI-style analysis and interactions in a standalone web page.
